<yaml-editor>

YAML in a <code-editor>, checked as it is typed by NimYAML's language server, which runs in a worker of the page: lint and JSON Schema diagnostics, completion of directives, hovers, formatting (Shift+Alt+F), the server's highlighting, and schema references as links (Ctrl/⌘+click).

Its own UI is one line: the path of the node at the cursor, as a JSON Pointer, a JSON Path or a URL fragment, copied when clicked. The page's files stay the page's: when the server needs one, a config or a schema, the editor asks with fileread, and a file open in another <yaml-editor> is read from it, as it is typed.

Du YAML dans un <code-editor>, vérifié pendant la frappe par le serveur de langage de NimYAML, qui tourne dans un worker de la page : diagnostics de lint et de schéma JSON, complétion des directives, survols, mise en forme (Maj+Alt+F), coloration du serveur, et références de schéma en liens (Ctrl/⌘+clic).

Son interface propre tient en une ligne : le chemin du nœud sous le curseur, en pointeur JSON, en chemin JSON ou en fragment d’URL, copié d’un clic. Les fichiers de la page restent ceux de la page : quand le serveur en a besoin, une configuration ou un schéma, l’éditeur les demande par fileread, et un fichier ouvert dans un autre <yaml-editor> y est lu, pendant la frappe.

YAML داخل <code-editor>، يُفحص أثناء الكتابة بخادم لغة NimYAML الذي يعمل في عامل (worker) من الصفحة: تشخيصات التدقيق ومخطط JSON، وإكمال التوجيهات، والتلميحات، والتنسيق (Shift+Alt+F)، وتلوين الخادم، ومراجع المخططات روابطَ (Ctrl/⌘+نقرة).

واجهته الخاصة سطر واحد: مسار العقدة عند المؤشر، مؤشرَ JSON أو مسار JSON أو جزءَ عنوان URL، يُنسخ بنقرة. وتبقى ملفات الصفحة للصفحة: حين يحتاج الخادم ملفًا، إعدادًا أو مخططًا، يطلبه المحرر بالحدث fileread، والملف المفتوح في <yaml-editor> آخر يُقرأ منه أثناء كتابته.

在 <code-editor> 中编辑 YAML，由在页面 worker 中运行的 NimYAML 语言服务器边输入边检查：代码检查和 JSON Schema 诊断、指令补全、悬停提示、格式化 （Shift+Alt+F）、服务器的语法着色，以及以链接呈现的 Schema 引用（Ctrl/⌘+点击）。

它自己的界面只有一行：光标所在节点的路径，可显示为 JSON 指针、JSON 路径或 URL 片段， 点击即可复制。页面的文件仍归页面所有：服务器需要某个文件（配置或 Schema）时，编辑器通过 fileread 事件请求；在另一个 <yaml-editor> 中打开的文件则 在输入时直接从中读取。

<code-editor> で編集する YAML を、ページの worker で動く NimYAML の 言語サーバーが入力中にチェックします。リントと JSON Schema の診断、ディレクティブの補完、 ホバー、整形（Shift+Alt+F）、サーバーによる色分け、 リンクになったスキーマ参照（Ctrl/⌘+クリック）に対応します。

独自の UI は 1 行だけです。カーソル位置のノードのパスを JSON ポインター、JSON パス、 URL フラグメントのいずれかで表示し、クリックでコピーします。ページのファイルはページの ものです。サーバーが設定やスキーマを必要とすると、エディターは fileread で求め、別の <yaml-editor> で開いているファイルは入力に合わせてそこから 読み取ります。

<code-editor> में YAML, जिसे पेज के worker में चलने वाला NimYAML का लैंग्वेज सर्वर टाइप करते समय जाँचता है: लिंट और JSON Schema निदान, डायरेक्टिव का स्वतः-पूरण, होवर, फ़ॉर्मैटिंग (Shift+Alt+F), सर्वर का रंगांकन, और लिंक के रूप में स्कीमा संदर्भ (Ctrl/⌘+क्लिक)।

इसका अपना UI एक पंक्ति है: कर्सर वाले नोड का पाथ, JSON पॉइंटर, JSON पाथ या URL फ़्रैगमेंट के रूप में, जो क्लिक करने पर कॉपी होता है। पेज की फ़ाइलें पेज की ही रहती हैं: जब सर्वर को कोई कॉन्फ़िग या स्कीमा चाहिए, एडिटर fileread से माँगता है, और किसी दूसरे <yaml-editor> में खुली फ़ाइल टाइप होते-होते वहीं से पढ़ी जाती है।
